# homebrew-decibri

Homebrew tap for decibri command-line tools.

## Install

```bash
brew tap decibri/decibri
brew install decibri-cli
```

Verify the install:

```bash
decibri --version
```

## Update and uninstall

```bash
brew upgrade decibri-cli
brew uninstall decibri-cli
```

## Available tools

- `decibri-cli`: audio capture, playback, and device listing from the terminal. See the [decibri CLI documentation](https://decibri.com/docs/apis/cli).
